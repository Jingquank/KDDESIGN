# design-morph rebuilds chrome and type live and crops media, with one media set on both sides

A morph could cross-fade two screenshots, which is cheap and shows nothing, or rebuild every pixel, which turns each photo into a guess. The film rebuilds what it can measure, chrome and type, as live boxes so every border, radius, color and letter can travel, and uses screenshot crops for what it cannot, photos and video frames. Real icons from both apps and the after-project's font are pulled in as files; a placeholder icon is never drawn.

Both sides show the same curated public media, chosen in the content question, so a tile on the old page and a tile on the new one are the same picture and travel one to one; personal photos and failed states are dropped by default. The cost is that the film is not a literal capture of either page, which is the point: it explains the redesign, not the user's account.
