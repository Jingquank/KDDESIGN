# Picks live in browser storage and reach the agent by paste

The page could have used the Artifact `db` capability so the agent reads ticks live with ArtifactData. We chose browser storage plus a copy CTA instead: ticks survive reloads on KD's machine, and the Pick sheet (the ticked Ideas by number and name) reaches the agent only when KD pastes it, together with what to do with them. Fewer moving parts per page, works for anyone who opens the link, and the pasted instruction, not the ticks, says what the next round does.
