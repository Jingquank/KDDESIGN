# crazy-prototype targets Claude Artifacts only

The imported skill set ships an `agents/openai.yaml` per skill so each one also runs under Codex, and a portable crazy-prototype would have needed a local-HTML fallback for agents without Artifacts. We decided the page is a Claude Artifact and nothing else: no fallback carrier, no project copy of the HTML, prototypes stay throwaway as KD's CLAUDE.md already requires. If another agent ever needs it, the fallback is a new decision, not a silent extension.
