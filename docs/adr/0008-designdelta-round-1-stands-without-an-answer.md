# A DesignDelta's Round 1 stands without an answer; the Record is written at hand-over

The first design ended every DesignDelta at Final: the user corrects Kinds and writes Notes, pastes them back, and only then does the agent write the Record. In practice the user mostly looks at Round 1 and moves on, so most DesignDeltas would never have reached the repo. Now the Record is written at hand-over from what the agent knows (transcripts and commit messages, each line sourced) and marked `Review: not reviewed (Round 1)`; pasted Notes later update it to `reviewed (Final)` and make the page static. The review mark matters because these Records are the raw material for distilling permanent design rules: a reviewed Record's lessons carry the user's check, an unreviewed one only the agent's reading.
