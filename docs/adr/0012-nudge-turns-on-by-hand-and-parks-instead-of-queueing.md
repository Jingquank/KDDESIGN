# The Nudge turns on with a hand run, and parks instead of queueing for the band

The first build asked in any repo with UI files (once, with "Never in this project" beside the keys) and drew only when the band above the prompt was empty, so it always gave way to the survey and to You Should Know. Both were wrong for different reasons. Headless and backend projects were asked about design work they never do, so now the Nudge is off in a project until the user runs `/design-delta` there by hand (or asks with `/nudge`); a project's own Deltas, even a teammate's, do not turn it on. And giving way was a choice, not a rule: a plugin the user installs runs ahead of built-in mods in the hook chain, and only the survey asks hooks to yield. Rather than rank itself against other bands, the Nudge takes the band when it is free and otherwise waits as one line in the status line (`$.ui.status`, one line per plugin, no keys), returning to the band once it is free; a running job's progress parks the same way. Nothing it has to say is lost, and it never fights another band for the digit keys.
