# Pages are saved as snapshots at the commits a Delta compares

ADR 0041 made a passive Delta text only, because its pictures were the slow part: a Before meant a worktree, an install and a dev server at the Baseline, then a browser driven by an agent, 26 minutes in ADR 0031. Without pictures a Design Lessons Review shows a Bad and a Good line and nothing to look at, and that review is now the one place a person decides. Getting the Before later is no answer: an old commit is hard to run, and harder each week.

The Before does not have to be rebuilt. It was on screen, in the user's own dev server, until the first edit; and the After of one Delta is the Before of the next. So the pages are saved while they are there:

- **A snapshot is one page as one file**: the protocol call `Page.captureSnapshot` writes MHTML, the markup with its CSS, images and fonts and no scripts. `viewer/snap.mjs` saves it with a headless Chromium it starts itself (an empty profile, never the user's browser) and renders it again at any width, so stills at 1440 and 390 come from one file. On a test site a page takes about 3 s to save and 1 s to render. A screenshot would fix the width and the crop at the moment nobody knows which surface a Change is on.
- **It is named by the commit its page shows**, in `<git dir>/kddesign/world/<commit>/`. Nothing is keyed by file or by branch, so there is nothing to reconcile: the Before of a Delta is the set at its Baseline, the After the set at the pushed tip. They are never in the work tree or a commit (KD: stills in the repo are too heavy).
- **The Nudge saves them at three moments**, only in a project recorded passively, only while no UI file differs from the commit and a dev server started from inside the repo is listening: after a push (every known route, and what the home page links to), at session start (the same at the Baseline, when missing), and before the first UI edit since the Baseline (the routes that file renders on). The third is the only one anybody waits for: the edit is held a few seconds, once per Baseline, because once it lands the page no longer shows the Baseline.
- **Which page a file renders on is learned, not asked**: each passive run names the route of every Change and `snap.mjs pair` writes it to `rooms.json`. Before that a file's route is its own in the common routers, else the local page a tool call last named. A wrong guess costs one unused page.
- **A passive run takes its stills from the pair** and reads each one, which gives back the eye ADR 0041 gave up. With a still it publishes a Design Changelog, so the pictures live where they always have (ADR 0006) and `/design-lessons` copies its examples from it unchanged. With none, the Delta is text, as in ADR 0041.
- **Cleaning is by what a set is for**: a set is kept while its commit is the Baseline or the pushed tip, two weeks past its last use otherwise, and the oldest go first past 300 MB. Deleting the clone deletes everything.

Coverage stays a matter of chance, on purpose: no server running, a route not yet known, a page behind a sign-in, a state reached only by a click, a canvas. Then the side has no still and the Delta's line carries the values. A signed-in page can be saved through the user's own browser (tried in Ego lite: the same protocol call, the same file) and taken in with `snap.mjs adopt`, which is left to the run and the user's rules.

Not chosen: a snapshot per edited file with rules for when it goes stale, which needed three conditions where the commit name needs none; holding every first edit of every file, when only the first edit since the Baseline meets a tree that still shows it; asking Claude to take the picture before editing, a step it may skip and that costs a refused tool call; `viewer/snapshot.js`, which saves a piece and its CSS for a Rebuilt frame and needs the surface named first; driving the user's browser from the mod, which opens tabs nobody asked for.

Still open: `/design-morph` could start from a kept pair, but its `tools/measure.js` waits for the page to come to rest, and a scripted wait never returned in a snapshot when tried; it needs a mode that measures without waiting.
