# prototype-fidelity is renamed iterate-it

The skill that raises a prototype toward the real product or lowers it to faux UI is now `/iterate-it`. The old name read as a concept rather than an action and was long to type; `iterate-it` names what the user does with it and sits beside `/break-it`. Fidelity stays the word for what the skill moves.

ADRs 0036 and 0039 keep the old name, as they were written under it.
