# A design-morph film lives only in its Artifact, and a redo rewrites one act in place

A Delta goes into git because a future agent needs its text (ADR 0004). A film has no such reader: its value is the page, and its data is coordinates and media crops that only the engine can use. So the Artifact is the only store. It is a multi-file Artifact: the page, `scene.json`, one file per act, the media crops, fonts and icons, and the engine files it loads. Nothing is written into the target repo, which also keeps a redesign film of someone else's product out of their history.

Redesigns keep moving after a film is made ("the library changed, redo it"). A redo finds the film by listing the user's Artifacts: a title ending in `Design Morph` and a `scene.json` among its files, which tells it apart from hand-built films with the same kind of title. One match is used; several are asked about; a link in the arguments wins. The run copies the files back, measures only that act's stored page pair again, rewrites that act's file, checks it, and republishes to the same URL, so a link already shared keeps working and the other acts do not change. The answers to the three questions are stored in `scene.json`, so a redo asks nothing. Not chosen: a copy of the scene in the repo or a local folder, which would drift from the published page the moment either is edited.
