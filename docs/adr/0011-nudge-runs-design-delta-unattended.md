# A Nudge's background run decides what design-delta would ask

`/design-delta` stops for the user three times: the scope question, each browser question, and the hand-over. A Nudge's **1** runs it in a background subagent so the conversation is never interrupted, and a background run cannot ask, so the mod settles each stop before the run starts. **Scope** is always the Unrecorded Changes: Baseline at the newest Delta's After on this branch, else the merge-base, so Deltas follow one another with no gaps, whichever conversation made the work. **After** is a snapshot of the working tree taken the moment **1** is pressed (`git stash create`, kept under `refs/design-delta/<folder>`), run in a detached worktree, because the main agent may go on editing; what it changes later belongs to the next Delta. **Browser** is always Ego lite, in a tab of its own, waiting while the main agent's turn is using a browser; this is a written exception to KD's rule of asking which browser every time, which still holds for every run started by hand. **Hand-over** is the band and a system notification, and pasted Notes or Verdicts work from any conversation because their header names the Delta. The one question left is the rules file when `/design-lessons` cannot resolve it: the band asks it after **1**, once per project, before the run starts.
