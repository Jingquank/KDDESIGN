# design-morph asks three questions; everything else is a fixed default

The first film's plan was confirmed over a long conversation: story order (three prototypes compared), player layout (three shells compared), pace (20 s per act, then 1.5× faster), captions, title cards, and which overlays to keep. Most of those answers would be the same for any film, and asking them again on every run costs the user more than a wrong default would. So every run asks only what differs per film and cannot be read from the code: the page pair for each act, the content (curated public media in place of personal photos and failed states), and which popups, toasts and popovers to include. The mapping of old elements to new ones is the model's own call; it asks only about the pairs it is unsure of and lists its other calls at the hand-over. Fixed and never asked: skeleton-first story order, about 13.3 s per act at 1× with 0.5×, 1× and 2×, captions in the project's language plus English (English only for an English product), a hard cut and title card between acts, and the Theater player. A maintainer tempted to add a question should first try making the default better; a film that needs a different pace is rare enough to ask for in plain text.
