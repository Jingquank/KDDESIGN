# The Nudge's 1 asks in the conversation, and Claude starts the run

The first build started the background run itself: pressing **1** called `$.agent.spawn` from the mod. Under auto mode that spawn goes through the same review as any Agent call, and the review reads only the conversation, where the keypress never appears; it refused the run as unrequested. A mod hook that approved its own spawn would have skipped that review, which is the point of auto mode, so it was not built. Instead **1** submits one line into the conversation in the user's name (the transcript still names the plugin): run the skill in the background, with the Agent call's description and prompt spelled out. Claude starts the agent, the review sees the request, and the band follows the agent from the moment it starts, known by its description; until then the band says the request is with Claude, and if the turn that took it ends without an agent, the band says so and Details points to the conversation. The cost is one visible line per run, against ADR 0011's quiet hand-off; the run itself still asks nothing. Work a run takes on, by **1** or by hand, counts as taken like **3**, so the Nudge stays quiet during a run and does not offer the same changes once it is done.
