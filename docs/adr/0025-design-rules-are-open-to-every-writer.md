# Design rules are open to every writer

ADR 0009 made `/design-lessons` the only writer of a project's design rules, and the pointer line told every agent to change them only through it. In practice that was too rigid: KD wants to fix a wording, add a rule he already knows, or let another agent or design harness update the project's design document without waiting for five Deltas and a review. So the design rules, and any design document or harness they live in, are open to every writer: the user edits them by hand or asks any agent or skill to. `/design-lessons` still writes only what pasted Verdicts decide, but it takes the section as it finds it, keeps a Rule written in directly as written (it never fills in sources nobody stated), touches only the entries the Verdicts name, and counts breaks of a hand-written Rule from the last review. The pointer line no longer says "change them only through /design-lessons", and a run drops that clause from an old line when it records. The evidence bar still guards the review path, so what the Deltas alone may turn into a rule is unchanged; only the claim that nothing else may write is gone.
