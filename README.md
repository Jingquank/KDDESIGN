# KDDESIGN

KD's design skills for coding agents. Each skill lives in `.claude/skills/<name>/` and is symlinked into `~/.claude/skills/<name>`.

- `crazy-prototype` — `/crazy-prototype <brief>`: as many prototypes as the brief admits on one Artifact page; tick or ✗ each Idea, paste the Pick sheet back for the next Round.
- `design-delta` — `/design-delta`: lay this conversation's or this branch's design Changes out Before beside After on one Artifact page, and write a text Record of the decisions into the target project's `docs/DesignDelta/`. Marking each New or Fix and pasting the Notes back is optional and makes the page its static Final. The page is a fixed viewer fed by `delta.json`.

Vocabulary: `CONTEXT.md`. Decisions: `docs/adr/`.
