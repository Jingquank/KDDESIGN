# KDDESIGN

KD's design skills for coding agents. Each skill lives in `.claude/skills/<name>/` and is symlinked into `~/.claude/skills/<name>`.

- `crazy-prototype` — `/crazy-prototype <brief>`: exhaust the design space onto one Artifact page of pickable prototypes, tick what you like, paste the Pick sheet back for the next Round.
- `design-delta` — `/design-delta`: lay this conversation's or this branch's design Changes out Before beside After on one Artifact page, mark each New or Fix, paste the Notes back for the shareable Final. The page is a fixed viewer fed by `delta.json`; only a text Record lands in the target project's `docs/DesignDelta/`.

Vocabulary: `CONTEXT.md`. Decisions: `docs/adr/`.
